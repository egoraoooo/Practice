Задание №8. Динамические библиотеки
Создана библиотека классов ICommand, содержащая
интерфейс.
Создана библиотека классов FileSystemCommands, в которой
определены реализации классов:
- DirectorySizeCommand (Вычисляет размер каталога, имя которого
 передается в конструктор.)
- FindFilesCommand (Находит все файлы в каталоге, удовлетворяющие маске.
Имя каталога и маска передаются как параметры конструктора.)
Создано консольное приложение CommandRunner,
которое динамически загружает библиотеку FileSystemCommands.
Реализован класс FileSystemCommandsTests, который позволяет
проверить работоспособность класса.
Все тесты пройдены успешно.
